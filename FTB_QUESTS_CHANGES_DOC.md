# Зміни у моді FTB Quests (`FTB-Quests-1.20.1-main`)

Цей мод був глибоко модифікований для повної інтеграції з динамічною системою островів SkyBlock та відмови від стандартного моду FTB Teams.

## 1. Глобальні зміни (Архітектура)

*   **Відмова від FTB Teams:** Всі згадки та залежності від `ftbteams` були видалені. Замість команд FTB мод тепер використовує власну систему команд, що базується на островах SkyBlock.
*   **Перейменування `TeamData` на `IslandData`:** Весь код, який раніше працював з даними команд (`TeamData`), тепер працює з `IslandData`. Це дозволило прив'язати прогрес квестів безпосередньо до ID острова (UUID власника).

## 2. Перевірки безпеки та острова

### `dev.ftb.mods.ftbquests.net.SubmitTaskMessage` (Здача квестів)
Додано критично важливі перевірки при спробі гравця здати завдання:
1.  **Перевірка членства:** Використовується `QuestTeamBridge`, щоб переконатися, що гравець дійсно є членом команди, якій належить острів.
2.  **Перевірка острова (`isCorrectIsland`):** Перевіряє, чи знаходиться гравець саме на СВОЄМУ сервері острова. Це запобігає експлойту, коли гравець міг би здавати квести на чужому острові, маючи доступ до іншого сервера.

### `dev.ftb.mods.ftbquests.net.ClaimRewardMessage` (Отримання нагород)
Аналогічно до здачі завдань, додано перевірку `isCorrectIsland`. Гравці можуть забирати нагороди тільки перебуваючи на своєму сервері.

---

## 3. Зв'язок з бекендом SkyBlock

### `dev.ftb.mods.ftbquests.quest.ServerQuestFile`
*   Метод `isPlayerOnTeam` тепер використовує `NestworldModsServer.ISLAND_PROVIDER.getCachedTeamId`.
*   Це дозволяє моду квестів миттєво дізнаватися про склад команди, який було завантажено з API бекенду.

### `dev.ftb.mods.ftbquests.quest.BaseQuestFile`
*   Метод `getOrCreateIslandData(Entity player)` тепер автоматично визначає ID острова гравця через `ISLAND_PROVIDER`.
*   Якщо дані про команду ще не завантажені або гравець не має острова, повертається спеціальний об'єкт `IslandData.UNLOADED`, що блокує прогрес квестів до моменту завантаження даних.

---

## 4. Збереження даних

### `dev.ftb.mods.ftbquests.quest.IslandData`
*   Дані про прогрес квестів кожного острова зберігаються у папці `world/ftbquests/`.
*   Файли мають назву `<UUID_власника>.snbt`.
*   У файл додано поле `members`, куди зберігаються UUID всіх членів команди на момент збереження, що забезпечує додаткову цілісність даних.
